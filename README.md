# Дослідження веб-доступності освітніх ресурсів

Автоматизований інструмент аудиту веб-доступності та аналізу університетських веб-сайтів за стандартами WCAG.

## Про проект

**Мета:** провести дослідження веб-доступності освітніх ресурсів шляхом розробки автоматизованого інструменту аудиту та аналізу вибірки українських і світових університетських веб-сайтів.

**Дослідницькі питання:**
1. Який рівень відповідності стандартам WCAG мають веб-сайти університетів України та світу?
2. Які типи порушень доступності є найпоширенішими?
3. Чи існує статистично значуща різниця між українськими та іноземними університетами?

## Технології

- **Backend:** .NET, ASP.NET Core Web API, Entity Framework Core
- **Frontend:** React
- **Аудит:** Playwright + axe-core
- **Database:** SQLite / PostgreSQL

## Архітектура
```
WebUI → WebAPI → Core → Domain ← Persistence
```

| Рівень | Проект | Опис |
|--------|--------|------|
| Presentation | WebUI | React frontend |
| Web API | WebAPI | REST API ендпоінти |
| Business | Core | Бізнес-логіка, аудит, аналітика |
| Data Access | Domain + Persistence | Моделі, репозиторії, БД |

## Функціональність

- **Одиночний аудит** - перевірка окремого URL
- **Пакетний аудит** - завантаження списку сайтів з CSV
- **Порівняльний аналіз** - порівняння груп (Україна vs Світ)
- **Візуалізація** - графіки, таблиці, експорт даних
